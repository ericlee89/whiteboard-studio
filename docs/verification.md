## Windows EPERM 修复与回归

## 小米 TTS 根目录配置加载修复

发现任务快照的 TTS 脚本只尝试读取快照 engine/.env，未主动读取原应用根目录配置。现已在隔离渲染器启动时加载原项目 .env，再通过子进程环境传递。没有复制密钥文件到任务目录，继承环境中已有值保持优先。错误提示改为要求与服务地址匹配的有效 TTS 密钥，不再暗示所有接口只接受 tp- 前缀。

10 项进程 / 配置回归通过。本地模拟 MiMo 接口的完整渲染流程通过：合成测试音频经 MiMo 适配器处理后，生成约 7.72 秒 H.264/AAC 测试视频，整段解码通过，任务中无 .env 或测试明文密钥。这是合成测试音与本地模拟接口，不是真实小米语音或付费服务验收；Windows/macOS 真机仍未验证。详见 mimo-config-fix.md 与 mimo-config-regression.json。
