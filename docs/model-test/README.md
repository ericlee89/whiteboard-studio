# 自定义模型本地集成测试

这是一组确定性本地接口测试，不代表任何真实模型或服务商的可用性。

已检查：设置页保存配置、元数据读回、模型 ID 选择、Chat Completions 流式请求、回复显示与刷新持久化、list-episodes 实际只读调用及工具结果回传。跨站保存和 URL 中携带认证信息被拒绝；默认私网地址校验仍有效。

聊天中文字体回退已修复。03-chat-response.png 与 04-tool-response.png 是修复后的实际截图。result.json 只记录测试状态、模型 ID、路径和鉴权是否匹配，不含真实密钥或完整请求正文。

复现：先安装项目及 engine 依赖、Playwright Chromium，然后在项目目录执行 `node scripts/verify-model-chat.mjs`。测试需要本机 4340、4341 端口空闲，使用隔离数据库和虚构测试身份，输出在 `.tmp/model-chat/`。测试接口只绑定 127.0.0.1，进程退出时关闭。

可用 WB_QA_CHROMIUM 指定浏览器可执行文件。脚本仅在隔离子进程中配置由操作者控制的本地端点和测试密钥，不修改应用正式配置，不发送真实模型请求。测试回复固定生成；list-episodes 工具的读取和返回由实际应用执行。
