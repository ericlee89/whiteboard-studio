# Studio surface design

Archetype: A5 Gallery and stage, direction studio-canvas. Existing source green replaces lime for primary and selection. Paper-white canvas, soft sage surrounding work area, quiet neutral inspector, vivid preview artwork and selected scene border.

The populated viewport shows a synthetic four-scene short, a live structured SVG layout preview, project gallery and selected narration. The signature object is the storyboard paired with beat-separated voice script. No setup wizard; settings and copy are peer inspector destinations.

Shared AgentSidebar handles polish/review/copy with bounded project context. Deterministic save, preview and render run actions. Project files are source-of-truth and jobs snapshot them. Status shows actual stages rather than timer-based fake progress.

Data density consciously favors one complete four-scene sample instead of fictional completed videos. No news claims, contacts or private exports are shipped.

390px: scene rail stays horizontally scrollable; inspector moves under canvas. Dark mode keeps paper artwork with dark UI surrounds.
