# 自定义模型更新

变更：设置页的提供商下拉新增「自定义（OpenAI 兼容）」，暴露基础地址、密钥、手动模型 ID 和配置显示名。可选读取模型列表。使用公共密钥存储、组织身份和模型选择接口；没有修改 node_modules，也没有复制 Core 运行时。

使用官方 toolkit/app-settings ejection 将设置界面转为应用拥有的源文件，保留 agent-native.ejections.json 用于升级比对。该版本官方单元闭包较大，包含版本匹配的相关 Toolkit UI。修正了其中旧聊天入口的公共导出引用。TypeScript 仍保持 strict；为适配官方源文件，将 lib 设为 ES2023，并关闭 exactOptionalPropertyTypes、noUncheckedIndexedAccess 两项额外收紧选项。

权限：同源 POST；必须登录；组织写入需要 owner/admin；组织限制个人提供商时拒绝普通成员的个人密钥写入。元数据读取不返回密钥。接口保存不发起推理请求，不依赖 /models；推理仍由框架校验地址并使用所选模型 ID。

验证：隔离开发数据库中使用无效占位密钥与 example.com 接口，证明手填模型保存、元数据读回、模型选择记录持久化，以及跨站保存返回 403。浏览器实际使用新增入口完成组织作用域保存。没有调用或宣称测试任何真实模型；占位凭证及测试数据库不进入源码包。

限制：同一作用域共用一套 OpenAI 兼容连接。显示名用于配置弹窗识别，模型选择器使用真实模型 ID。未扩展为多个独立网关提供商。
